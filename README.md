# Nutrition Site
# Nutrient Plan: Redefining Healthy Eating in the Social Media Era

## 📌 Project Overview
This website is developed as part of a psychology research project exploring the impact of social media on body image and dietary habits (the "mafia" of social media). We aim to reduce restrictive dieting, over-exercising, and over self-checking by shifting the focus away from calorie counting.

## 🧠 Core Psychological Interventions
1. **Pre-emptive Check-in (Quiz):** A gentle SCOFF/BDDQ-based quiz to assess the user's current mental state and provide tailored, non-triggering feedback.
2. **Nutrient-Focused Nutrition:** No calories. Personalized nutrient targets (Protein, Fat, Fiber) based on body metrics.
3. **Intuitive Eating (Fridge & Satiety):** Encourages using available food and evaluating fullness based on body size, not strict calorie limits.
4. **Algorithm Control (Digital Detox):** Helps users retrain their social media feed by tracking screen time and promoting positive searches.
5. **Mindful Diary & Behavior Tracker:** Tracks moods (visualized in a red/green distribution chart) and eating behaviors (hunger/binge) to show progress without judgment.

## 💻 Tech Stack
Pure HTML/CSS/JS. Deployed via GitHub Pages. Features local storage for data persistence.
